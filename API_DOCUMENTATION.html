🚀 Introduction & Setup

Base URL: http://localhost:5000/api

Environment & Testing

Local Development: http://localhost:5000/api
Testing Tools: Postman, Insomnia, Thunder Client
Note: All protected endpoints require JWT token in Authorization header

Authentication Header Format

Authorization: Bearer {JWT_TOKEN}

CORS Allowed Origins

http://localhost:3000 http://localhost:3001 http://localhost:3002 http://localhost:3003 http://localhost:3005 http://127.0.0.1:3000-3005

🔐 Authentication & Authorization

JWT Token Structure

JWT tokens contain user ID, role, and permissions. Token expires in 7 days.

{ "id": "user_mongo_id", "role": "user|admin|superadmin", "permissions": ["permission1", "permission2"], "iat": 1234567890, "exp": 1234654290 }

User Roles

Role Description Permissions
user Regular user/player Create bookings, view turfs, write reviews
admin Venue admin/operator Manage own turfs, manage bookings, view analytics
superadmin System administrator Full system access, manage all users, RBAC

👤 Authentication Endpoints

Base path: /api/auth

POST /register

Register a new user account

Request Body

Parameter Type Description
name Required string Full name of the user
email Required string Valid email address (must be unique)
phone Required string 10-digit Indian mobile number (6-9 followed by 9 digits)
password Required string Min 8 chars, 1 uppercase, 1 number, 1 special character
confirmPassword Required string Must match password field

Test Data - Request

{ "name": "Raj Kumar", "email": "raj.kumar@example.com", "phone": "9876543210", "password": "SecurePass@123", "confirmPassword": "SecurePass@123" }

Success Response - 201 Created

{ "msg": "User registered successfully", "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...", "user": { "_id": "507f1f77bcf86cd799439011", "name": "Raj Kumar", "email": "raj.kumar@example.com", "phone": "9876543210", "role": "user", "permissions": [], "isActive": true, "coins": 0, "createdAt": "2026-05-13T10:30:00.000Z" } }

Error Responses

400 Bad Request
{ "msg": "All fields are required" }
400 Bad Request
{ "msg": "Passwords do not match" }
400 Bad Request
{ "msg": "Invalid phone number format. Must be a valid 10-digit Indian number." }

💡 Testing Tips

  • Email must be unique - can't register same email twice
  • Phone number must be a valid 10-digit Indian number
  • Password must have uppercase, number, and special character
  • Save the JWT token for subsequent API calls
